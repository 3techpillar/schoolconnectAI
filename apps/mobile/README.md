# SchoolConnect Mobile

Family MVP (React Native CLI). Shares the same Next.js API as web.

**Full setup:** [docs/MOBILE.md](../../docs/MOBILE.md) · **Docs hub:** [docs/README.md](../../docs/README.md) · **Root README:** [../../README.md](../../README.md)

```bash
# from monorepo root
npm run dev:web      # API on :3000
npm run dev:mobile   # Metro
# set apps/mobile/.env → API_BASE_URL (see docs/MOBILE.md)
```
