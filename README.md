# SchoolConnect AI

Next.js app for school communication (attendance, homework, fees, circulars, bus tracking, AI assistant).

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Demo OTP: `000000`

## Build / deploy

```bash
npm run build   # generates .next/
npm start
```

## Stack

- Next.js 15 (App Router)
- React 19
- TypeScript
- Plain CSS (no Tailwind / UI kits)
